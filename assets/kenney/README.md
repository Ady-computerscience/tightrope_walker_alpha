# Kenney assets

Selected files from Kenney packs:

- [Blocky Characters 2.0](https://kenney.nl/assets/blocky-characters): `character-a.glb` and its texture, used for the animated walker.
- [Holiday Kit 2.0](https://kenney.nl/assets/holiday-kit): bench and present models used as tower decorations.
- [Platformer Kit 4.1](https://kenney.nl/assets/platformer-kit): `flag.glb` and its color map, available for the gust warning.

All three packs are **CC0 1.0**. Their original `License.txt` files are preserved in their respective folders. The archives were downloaded from Kenney's [Blocky Characters](https://opengameart.org/content/3d-rigged-characters), [Holiday Kit](https://opengameart.org/content/holiday-kit), and [Platformer Kit](https://opengameart.org/content/platformer-kit-remade) uploads on OpenGameArt because the direct Kenney archive endpoint returned HTTP 403 in this environment. Only selected models and their required texture files are included.
