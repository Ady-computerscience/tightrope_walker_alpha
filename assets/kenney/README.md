# Kenney assets

Selected files from Kenney packs:

- [Blocky Characters 2.0](https://kenney.nl/assets/blocky-characters): `character-a.glb` and its texture, used for the animated walker.
- [Holiday Kit 2.0](https://kenney.nl/assets/holiday-kit): bench and present models used as tower decorations.

Both packs are **CC0 1.0**. Their original `License.txt` files are preserved in their respective folders. The archives were downloaded from Kenney's [Blocky Characters](https://opengameart.org/content/3d-rigged-characters) and [Holiday Kit](https://opengameart.org/content/holiday-kit) uploads on OpenGameArt because the direct Kenney archive endpoint returned HTTP 403 in this environment. Only selected models and their required texture files are included.
