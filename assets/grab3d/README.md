# Elderly Man character

Stylized, rigged Elderly Man by [Grab3D](https://grab3d.com/models/characters/elderly-man/), used under CC0 1.0. The source includes a flat cap, glasses, white moustache, cardigan, and walking animation. This rigged GLB is scaled and posed in `scripts/game.gd` so both hands reach the balance pole.

The original license and manifest are included here. Grab3D identifies the asset as AI-assisted in `LICENSE.txt`.
